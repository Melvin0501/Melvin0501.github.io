# melvin-huang-site

Personal website of Lung Hsiang (Melvin) Huang, built with [Astro](https://astro.build).

```bash
npm install
npm run dev      # preview at http://localhost:4321
npm run build    # production build in dist/
```

Content lives in `src/data/profile.ts` and `src/data/items.ts`. See `CLAUDE.md` for details.
